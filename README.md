# xlsft Homebrew tap

Homebrew casks for xlsft tools, for macOS and Linux.

```sh
brew install xlsft/tap/<tool>
```

| Tool | |
|---|---|
| [ymcp](https://github.com/xlsft/ymcp) | YouTrack MCP server: `brew install xlsft/tap/ymcp` |

Casks are written by each tool's release workflow ([GoReleaser](https://goreleaser.com)); don't edit them by hand.
To add a tool, point its `homebrew_casks` at this repository.
